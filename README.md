# 國際法動態追蹤

網站：https://christopherpyliu-a11y.github.io/intl-law-tracker/

網站分為兩部分，每則動態都附白話脈絡摘要（白話摘要、背景、事實、爭點、見解、意義）與原始資料連結：

- **國際公法**：國際法院（ICJ）、國際刑事法院（ICC）、歐洲／美洲／非洲人權法院、國際海洋法法庭（ITLOS）的最新判決與動態，以及 EJIL:Talk!、Opinio Juris 上涉及傳統國際法、種族滅絕與 ICC 的評論文章。
- **國際仲裁法**：國際商務仲裁與投資條約仲裁（以國家為被申請人）的法院裁判、仲裁判斷、仲裁機構動態、ISDS 改革與評論，可依「商務仲裁／投資仲裁」篩選。直接連結：`#arb`。

功能：每則附「備忘錄版」正式摘要（可一鍵複製）；「案件追蹤」把同一案件的動態串成時間軸（連結格式 `#case-案件代號`）；「即將到來」的日期可加入 Google 行事曆或下載 .ics；可切換只看法院動態或評論。

檔案：

- `index.html`：網站頁面
- `data.json`：國際公法的動態與時程資料
- `arbitration.json`：國際仲裁法的動態與時程資料
- `digest.json`：每週重點（每週一早上更新）

兩份資料每日台北時間 06:50、22:50 自動更新。
